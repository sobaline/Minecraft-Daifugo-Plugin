# Minecraft Daifugo Plugin (PaperMC)

Minecraft（PaperMC）のマルチプレイサーバー上で、2〜6人で遊べる「大富豪」プラグインです。
コマンド操作を最小限に抑え、ゲーム内のテーブルとホログラムUIを使って直感的にプレイできる設計を目指しました。

## 使用技術・開発環境
* **言語:** Java
* **サーバーAPI:** PaperMC
* **IDE:** IntelliJ IDEA
* **開発プロセス:** 生成AI（コーディング支援・壁打ち）を活用しつつ、要件定義・状態管理の設計・デバッグおよび実機テストを主導

## 主な機能
* **マルチプレイ対応（2〜6人）**
  * 円卓形式での着席・観戦モード（手札の裏面表示）に対応
* **直感的なUI/UX**
  * ホログラム表示や当たり判定を活用した、ゲーム内でのカード選択・プレイ操作
* **豊富なローカルルール実装**
  * 革命 / 8切り / 4止め / 5スキップ / 7渡し / 9リバース / Qボンバー / ジョーカー
  * 連戦時の階級決定およびカード交換処理

## 技術的な工夫・解決した課題
開発・実機テストの中で発生した以下の課題を特定し、修正を行いました。

1. **UUIDベースのプレイヤー状態管理**
   * プレイヤー名ではなくUUIDで管理することで、試合中の切断・再接続時にもゲームが破綻しない安定性を確保しました。
2. **エンティティのライフサイクル管理**
   * カードやUIとして生成するエンティティ（ホログラム等）の当たり判定の調整と、試合終了時・異常終了時の確実なクリーンアップ処理を実装し、サーバー負荷やゴミデータの残留を防ぎました。
3. **複雑なルール間の状態遷移（ステート管理）**
   * 「革命＋複数枚出し＋特殊効果」など条件が重なるケースを整理し、ターンの進行や勝敗判定に矛盾が出ないようロジックを分離しました。
